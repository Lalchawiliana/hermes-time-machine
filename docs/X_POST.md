Hermes Time-Machine ⏪

I built a native Hermes Agent plugin that routes terminal commands into a restricted Docker workspace, checkpoints changed files, and lets you inspect and restore tracked files from a Desktop timeline.

Execution middleware + local recovery journal + Desktop SDK. Built for the @NousResearch Hermes Agent Plugin Hackathon.
